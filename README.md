# harness-architecture

Architecture work for the harness project — planning and analysis phase only.

## Scope

Pure architecture: planning → analysis → planning. No implementation.

The harness goal is to enable frictionless development across projects (mobile, web, KMP, backend) with consistent rules, skills, agents, and pipelines.

## Layout

```
harness-architecture/
  docs/          # research notes, references, external sources
  decisions/     # ADRs (Architecture Decision Records)
  diagrams/      # C4, arc42, sequence, dependency graphs
  drafts/        # work-in-progress proposals
```
