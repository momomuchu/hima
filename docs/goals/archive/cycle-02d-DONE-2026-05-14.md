# Short-Term Goal — Cycle 02d: SubagentStop Deliverables Gate

## 1. Why this cycle

Cycle-02c made deterministic routing executable. The next blocker is delegated-work integrity:
`subagent_stop` currently checks for an accepted trace, but it does not prove that a planned
subagent actually produced its declared deliverables.

This cycle implements SYNTHESIS pattern #15: a SubagentStop deliverables gate adapted from the
OMC `verify-deliverables.mjs` pattern.

## 2. Deliverables

| # | File | Content |
|---|------|---------|
| C2D-1 | `packages/core/src/schemas/run-set.schema.ts` | Subagent run records can declare expected deliverable paths. |
| C2D-2 | `packages/core/src/gates/evaluate-gate.ts` | `subagent_stop` blocks declared deliverables that are missing, outside the project, or not tied to the returned subagent. |
| C2D-3 | `packages/core/test/gates.test.ts` | Gate tests for missing deliverables, delivered files, malformed paths, and existing trace behavior. |

| C2D-5 | `docs/conception/05-gates-policy-spec.md` | Amend the gate spec to define deliverables verification as part of `subagent_stop`. |

## 3. DONE criteria (saturation-enforced)

This cycle reaches `status: DONE` when ALL of:

1. **Declared deliverables are first-class** — a subagent run record can declare deliverable paths without relying on untyped catchall metadata.
2. **SubagentStop enforces deliverables** — if a declared deliverable is missing, invalid, or outside the project, `subagent_stop` returns a blocking violation.
3. **Trace behavior remains intact** — existing accepted-evidence trace behavior still passes, and missing traces still warn/block per policy.
4. **Tests cover the edge cases** — focused tests prove missing files, present files, outside paths, and hook-level payload/event behavior.
5. **Spec amendment landed** — `docs/conception/05-gates-policy-spec.md` documents deliverables verification and the failure mode.
6. **Verification passes** — `corepack pnpm typecheck`, `corepack pnpm build`, `corepack pnpm lint`, and `corepack pnpm test` are green.
7. **Saturation check** — a critic pass tries to find bypasses, stale spec/code drift, weak path validation, and untested SubagentStop branches. Any material finding reopens the cycle.
