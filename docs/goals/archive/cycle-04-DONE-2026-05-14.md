bounded-context map for `packages/core/` before moving code. This prevents C2-C7 from becoming

## 3. DONE criteria (saturation-enforced)

This cycle reaches `status: DONE` when ALL of:

1. **Six contexts exist** — Run, Cycle, Gate, Skill, Subagent, and Evidence each have a responsibility statement and ownership boundary.
2. **File inventory is complete** — `rg --files packages/core/src` has no source file missing from `core-file-to-context.csv`.
3. **Ambiguous ownership is resolved** — Run vs Cycle and Gate vs Evidence decisions are explicit.
4. **Forbidden dependencies are named** — at least two forbidden ownership leaks are documented.
5. **Migration implications exist** — C2-C7 each have an implication row and the first safe refactor step is selected.
6. **Spec verification report passes** — C1-AC-01 through C1-AC-07 each map to accepted evidence.
7. **Verification passes** — `corepack pnpm lint` and `corepack pnpm --filter @harness/core test -- --runInBand` are green.
8. **Saturation check** — a critic pass tries to find hidden seventh contexts, missing files, vague boundaries, service-layer leakage, and premature refactor claims. Any material finding reopens the cycle.
