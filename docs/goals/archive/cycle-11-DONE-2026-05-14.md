## 3. DONE criteria (saturation-enforced)

This cycle reaches `status: DONE` when ALL of:

1. **Aggregate behavior is primary** - Run-owned transition/invariant tests exercise `RunAggregate` where feasible, with service tests limited to delegation/API compatibility.
2. **Storage mechanics are secondary** - event-log, ledger, and repository tests verify compatibility without replacing aggregate behavior assertions.
3. **Coverage is preserved** - transition persistence, governance payloads, event-log entries, ledger entries, redaction, invariant rejection, and no-partial-write behavior remain covered.
4. **Ownership stays clean** - Cycle, Gate, Evidence, and repository tests keep their own concerns instead of being collapsed into Run tests.
5. **No production churn** - C7 does not introduce behavioral production changes except minimal test seams if unavoidable.
6. **Truth surfaces align** - C7 implementation note identifies which tests are aggregate-owned and which intentionally remain service/storage tests.
7. **Regression suite stays green** - test count may change only with an explicit explanation in the C7 note.
8. **Verification passes** - `corepack pnpm --filter @harness/core test -- --runInBand`, `corepack pnpm lint`, and `corepack pnpm build` are green.
9. **Saturation check** - a critic pass tries to find service-mechanics assertions masquerading as aggregate behavior, lost coverage, stale truth surfaces, and production refactor leakage. Any material finding reopens the cycle.
