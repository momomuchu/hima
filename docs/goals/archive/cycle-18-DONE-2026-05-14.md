## 3. DONE criteria (saturation-enforced)

This cycle reaches `status: DONE` when ALL of:

1. **Gate types are explicit** - `pre_compact` and `post_compact` are first-class canonical gate types and schema-accepted hook events.
2. **PreCompact contract is explicit** - runtime payload fields are normalized and a bounded critical-state snapshot is returned or persisted without leaking secrets.
3. **PostCompact contract is explicit** - runtime payload fields are normalized and compaction continuity is checked against the current route/run context.
4. **Planning-state failure stays fail-closed** - missing or unreadable planning state blocks instead of silently allowing compact hooks to execute.
5. **Secrets stay redacted** - compact summaries, transcript/context previews, and gate reasons do not persist known secret patterns.
6. **Dry-run is safe** - dry-run/equivalent does not append events or mutate planning state.
7. **Scope stays narrow** - no PreToolUse, SessionStart, Stop, UserPromptSubmit, PostToolUse expansion, SubagentStart policy, MCP, prompt, skill-lint, hook-decomposition, or migration work lands.
8. **Truth surfaces align** - implementation note, master checklist, and current short-term goal describe exactly what landed and what remains.
9. **Verification passes** - focused compact hook tests, full core tests, `corepack pnpm lint`, `corepack pnpm docs:index`, and `corepack pnpm build` are green.
10. **Inventory stays truthful** - `core-file-to-context.csv` matches `packages/core/src` if source files change.
11. **Saturation check** - a critic pass tries to find hook overclaim, fail-open behavior, redaction gaps, dry-run mutation, stale docs, and insufficient negative tests. Any material finding reopens the cycle.
