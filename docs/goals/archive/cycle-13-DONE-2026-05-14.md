## 3. DONE criteria (saturation-enforced)

This cycle reaches `status: DONE` when ALL of:

1. **Reference model is verified** - the OpenHands scope claim is checked against primary source and explicitly corrected before implementation.
2. **Four durable HIMA scopes are represented** - public, user, project, and org skill scopes have explicit path semantics in code/tests.
3. **Precedence is deterministic** - resolver behavior is documented and tested when the same skill name appears in multiple scopes.
4. **Installer is schema-gated** - installed `SKILL.md` content is validated through Cycle-12 `SkillFrontmatterSchema` before write planning.
5. **Dry-run remains read-only** - planning can show intended writes without mutating the filesystem.
6. **Path safety is enforced** - skill names and scope roots cannot escape their intended directories.
7. **Scope stays narrow** - no hooks, MCP tools, prompt-file generation, skill lint rules, or bulk imported skills are implemented.
8. **Truth surfaces align** - implementation note, master checklist, and inventory describe exactly what landed.
9. **Verification passes** - focused skill install/resolver tests, full core tests, `corepack pnpm lint`, `corepack pnpm docs:index`, and `corepack pnpm build` are green.
10. **Saturation check** - a critic pass tries to find source mismatch, precedence ambiguity, path traversal, schema bypass, dry-run mutation, install-scope leakage, stale docs, and insufficient negative tests. Any material finding reopens the cycle.
