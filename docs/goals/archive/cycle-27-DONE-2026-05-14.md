# Short-Term Goal - Cycle 27: Stream E Adapter Production Foundation

## 1. Result

Cycle 27 closed the adapter production foundation for all three first-party adapters.

The implementation adds package-local `system-prompt.md` files and profile-backed `hook-bindings.ts`
modules for Claude Code, Codex, and Hermes. Adapter package tests now prove prompt presence,
runtime-profile alignment, and explicit unsupported/degraded hook behavior.

This is not production-ready adapter evidence. Install command wiring and real-runtime E2E sessions
remain open.

false real-runtime claims, hidden install behavior, missing docs-index rows, and unsupported hooks
presented as blocking.

Findings and fixes:
