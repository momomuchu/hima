## 3. DONE criteria (saturation-enforced)

This cycle reaches `status: DONE` when ALL of:

1. **SubagentStart contract is explicit** - the implementation note states which launch signals are evaluated and which remain future work.
2. **Scope is enforced** - subagent launches without bounded task/scope or allowed file/write surface are blocked or fail closed.
3. **Depth is enforced** - configured maximum recursion/delegation depth is represented and tested for over-depth denial.
4. **Risk policy is enforced** - higher-risk launches require explicit evidence contract and cannot silently downgrade required review.
5. **Evidence contract is explicit** - launch events record the expected deliverables/evidence without fabricating accepted evidence.
6. **Secrets stay redacted** - launch prompts, payload previews, tool outputs, and persisted events redact known secret patterns.
7. **Dry-run is safe** - dry-run/equivalent does not append events or mutate planning state.
8. **Scope stays narrow** - no PostToolUse, PreToolUse, SessionStart, Stop, UserPromptSubmit, PreCompact/PostCompact, SubagentStop, MCP, adapter, prompt, skill-lint, hard-limits, hook-decomposition, or migration work lands.

10. **Verification passes** - focused SubagentStart tests, full core tests, `corepack pnpm lint`, `corepack pnpm docs:index`, and `corepack pnpm build` are green.
11. **Inventory stays truthful** - `core-file-to-context.csv` matches `packages/core/src` if source files change.
