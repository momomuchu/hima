# Short-Term Goal - Cycle 21: Stream D Hook Decomposition / Adapter Hardening

## 1. Why this cycle

Cycles 16-20 closed the D-hook semantics in-place: PreToolUse, SubagentStop, SessionStart,
UserPromptSubmit, Stop, PreCompact/PostCompact, PostToolUse expansion, and SubagentStart policy now
have tested fail-closed behavior and truth-surface docs. The remaining D-H6 work is structural:
`packages/core/src/gates/evaluate-gate.ts` and `packages/core/src/services/handle-hook.ts` now carry
too many hook concerns in large shared files. The next cycle decomposes those concerns into focused
hook/gate modules while preserving behavior.

This cycle is refactor and adapter-hardening only. It must not change gate semantics, add hard-limits
or permission-judge behavior, add MCP tools, create adapter package features, alter prompt files,
change skill linting, or migrate unrelated catalog/install code.

## 3. DONE criteria (saturation-enforced)

This cycle reaches `status: DONE` when ALL of:

1. **Behavior is preserved** - existing hook/gate decisions, violation types, event payloads, redaction, dry-run behavior, and runtime binding checks remain compatible.
2. **Boundaries are clearer** - extracted modules have narrow responsibilities and no circular ownership between service orchestration, normalization, evaluation, persistence, and policy utilities.
3. **No semantic creep** - no new policy, permission model, hard-limit, MCP, adapter-package, prompt, or skill-lint behavior lands.
4. **Public API stays stable** - exported core APIs used by packages/tests remain compatible.
5. **Truth surfaces align** - implementation note, master checklist, and current short-term goal describe exactly what changed and what remains.
6. **Verification passes** - focused hook/gate tests, full core tests, `corepack pnpm lint`, `corepack pnpm docs:index`, and `corepack pnpm build` are green.
7. **Inventory stays truthful** - `core-file-to-context.csv` matches `packages/core/src` after any source-file extraction.
8. **Saturation check** - a critic pass tries to find behavior drift, lost redaction, dry-run mutation, event-shape drift, stale docs, circular boundaries, and insufficient regression coverage. Any material finding reopens the cycle.
