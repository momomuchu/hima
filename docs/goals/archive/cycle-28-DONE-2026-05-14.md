# Short-Term Goal - Cycle 28: Stream E Install Command Wiring

## 1. Result

Cycle 28 closed package/CLI install command wiring for all three first-party adapters.

The implementation adds `src/install.ts` modules to Claude, Codex, and Hermes adapters, exports them
as `@harness/adapter-*/install`, and moves CLI install apply/remove dispatch through those
adapter-owned modules.

This is not real-runtime E2E evidence. It proves package/CLI install dispatch shape only.

## 4. Saturation Critic

Cycle 27/28 truth surfaces, false E2E claims, unsupported hooks described as blocking, and missing
docs-index rows.

Findings and fixes:

- CLI install dispatch still imported low-level adapter functions directly. Fixed by routing through
  `@harness/adapter-*/install`.
- Adapter package builds initially exposed only `dist/index.js`. Fixed by building `src/install.ts`
  and exporting `./install`.
- Prompt material would otherwise be absent from package files. Fixed by including
  `src/system-prompt.md`.
- Cycle 27 foundation docs still described Cycle 28 as future work. Fixed to point to Cycle 28
  closure.

After fixes, no material Cycle 28 blocker remains.
