## 3. DONE criteria (saturation-enforced)

This cycle reaches `status: DONE` when ALL of:

1. **Repository exists** — `RunRepository` is a named adapter over existing planning-store behavior, not a second storage implementation.
2. **Adapter stays thin** — business rules, transition legality, gate policy, event taxonomy, and invariants remain outside the repository.
3. **Compatibility remains intact** — existing planning files, run-set events, event-log entries, and ledger behavior keep their shape.
4. **Run aggregate boundary improves** — Run-owned persistence calls use the repository where appropriate without broad service churn.
5. **Tests prove behavior** — focused tests cover repository read/write/event append behavior and at least one aggregate path that uses it.
6. **No broad refactor leak** — C5 does not implement C6 invariant relocation or C7 aggregate-style test rewrites.
7. **File inventory is current** — C1 CSV includes new repository files.
8. **Verification passes** — `corepack pnpm --filter @harness/core test -- --runInBand`, `corepack pnpm lint`, and `corepack pnpm build` are green.
