## Purpose

Resolve genuine ambiguity before a threshold is crossed, without the cost of a serial
one-question-at-a-time interrogation. Presents every open question as a single numbered
batch the user can answer in one pass.

## When to use

- A true blocker exists: no safe reversible default is available for a decision that
  materially changes scope, safety, or direction.
- Multiple independent open questions have accumulated — batch them, don't drip them.
- Never as a first-turn questionnaire on a broad or exploratory request — propose with
  reversible assumptions first; only parley when a real blocker remains.

## Steps

- Collect every genuinely blocking open question across the current scope of work.
- Cap the batch at a small number (≤5) — if there are more, the scope is too broad; narrow it.
- Present them as one numbered markdown list, plain language, each question self-contained.
- State the reversible default you'd take for any question left unanswered.
- Proceed on defaults for non-blocking ambiguity; only wait on true blockers.

## Done when

- All genuine blockers are surfaced in a single batch, not serial prompts.
- Every non-blocking ambiguity was resolved with a stated reversible default instead of asked.
